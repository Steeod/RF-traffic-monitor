Capture method
WSL2 guide for AWUS036ACS
  1. Install the bundled usbipd-win package (Microsoft WSL is not changed).
  2. Find the BUSID with usbipd list, enter it above, and save.
  3. Share the USB device, then attach it.
  4. Install the RTL8811AU monitor-mode driver inside Ubuntu.
  5. Check the backend again and enable ✓ Remote ID.

While the Alfa adapter is attached to WSL2, it is unavailable in Windows. The driver build uses the bundled Microsoft kernel source and rtw88/RTL8811AU source. Only basic Ubuntu build packages are installed from official repositories when missing.

Wi-Fi Remote ID inactive

Do not use Zadig/WinUSB with the Alfa adapter. The Windows WLAN backend remains the simplest option for Wi-Fi Beacon Remote ID.
