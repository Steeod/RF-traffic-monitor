# RF Traffic Monitor 0.10.1 beta

This update addresses confirmed packaging and map/UI issues. It does not yet
establish the cause of every reported receiver failure. Real V3/V4 reception
on affected computers still needs testing.

## Existing installations

1. Close RF Traffic Monitor with its Exit button. Close any remaining Start.cmd
   window. Do not update while a decoder or map download is running.
2. Make a backup copy of your current application folder.
3. Extract `RFTrafficMonitor-0.10.1-update.zip` into the folder containing
   `Start.cmd`, accepting replacement of the included application files.
4. Start with `Start.cmd` and press Ctrl+F5 in the browser.
5. Check that the browser tab title contains `0.10.1`. Run Check receiver,
   select ADS-B only for the initial test, and start Automatic cycle.

The patch does not contain config.json, maps, captures, logs or driver installers.
It preserves your settings and downloaded maps. To roll back, close the app and
restore the backup folder.

## Changes

- ADS-B now bundles the pinned RTL-SDR Blog V1.4.0 x86 runtime libraries required
  by the 32-bit dump1090 executable, including support for Blog V4 hardware.
- An unset map center follows station coordinates; an explicitly separate map
  center remains supported. For a new unconfigured installation, the viewport
  uses the bundled map region instead of showing the Gulf of Guinea.
- Downloading a region saves that map center. The browser detects the completed
  map replacement and reloads metadata and tile images automatically.
- Errors from reception commands remain visible across status polling, until
  another Start/Stop/Demo attempt. Backend error messages remain supported.

For maps, enter the station coordinates and Save. If you previously chose a
different map center, update the two Map-center fields explicitly. Download
the region if it is not already included. Existing coastlines/place labels
are not regenerated by the satellite download.

## New installation

Use `RFTrafficMonitor-0.10.1-Setup-win64.exe` and choose an empty folder.
The full setup is unsigned; optional Npcap and Windows WSL setup remain separate.
Driver downloads still go into vendor/drivers and USB driver installation still
requires selecting the correct physical device in Zadig.
